Política de privacidad

Cómo BLINDSHOT Assistant trata la información de los servidores y las personas que lo usan.

Última actualización: 19 de septiembre de 2026 Se aplica a: bot de Discord y sitio web

Resumen: BLINDSHOT Assistant guarda lo mínimo para funcionar (identificadores y ajustes del servidor). No lee ni almacena el contenido de tus conversaciones, no vende datos y no los usa con fines publicitarios.

1. Datos recopilados

El bot solo almacena la información necesaria para prestar sus funciones. En concreto:

  • Identificadores de servidor (guild ID) y de los canales y roles que se configuran como destino de una función.
  • Identificadores de usuario (user ID) de los miembros afectados por una acción de moderación, verificación o progreso de comunidad.
  • Ajustes del servidor: canal de bienvenida, canal de sugerencias, rol de verificación, prefijos y opciones activadas.
  • Registros de moderación: tipo de acción, motivo indicado por el moderador, identificador de quien la ejecuta y marca de tiempo.
  • Datos de actividad cuando el sistema de niveles está activo: recuento de mensajes o experiencia acumulada asociada a un user ID.
  • Registros técnicos: errores y uso de comandos, para diagnosticar fallos.

No se almacena el contenido de los mensajes. Los mensajes que el bot procesa para ejecutar un comando se tratan en memoria y no se conservan, salvo el texto que la persona envía voluntariamente a una función pública como una sugerencia o una encuesta.

2. Datos procedentes de Discord

Al invitar al bot, Discord le concede acceso a determinada información del servidor según los permisos y los intents concedidos. Esa información puede incluir el nombre de usuario, el avatar, los roles y la fecha de entrada al servidor. Estos datos se consultan en el momento en que se necesitan y solo se guardan los identificadores descritos en el apartado anterior.

El uso de Discord se rige además por los Términos de servicio y la Política de privacidad de Discord. BLINDSHOT Assistant no está afiliado a Discord Inc.

Si en el futuro se habilita el inicio de sesión mediante Discord OAuth2, se solicitará el consentimiento explícito y únicamente se pedirán los permisos mínimos necesarios (identidad básica y lista de servidores). Esta política se actualizará antes de activar esa función.

3. Datos relacionados con Roblox

Si activas la vinculación de cuentas de Roblox, el bot podrá guardar:

  • El identificador numérico de Roblox y el nombre de usuario de la cuenta vinculada.
  • La relación entre ese identificador y el user ID de Discord correspondiente.
  • El código de verificación temporal generado durante el proceso, que se invalida al completarse o al caducar.

La verificación se realiza mediante información pública del perfil de Roblox. El bot nunca solicita ni almacena contraseñas, cookies de sesión ni credenciales de Roblox, y ninguna persona debe compartirlas. La vinculación es voluntaria: solo se produce si la persona ejecuta el comando correspondiente.

BLINDSHOT Assistant no está afiliado a Roblox Corporation. El uso de Roblox se rige por sus propias condiciones y política de privacidad.

4. Uso de los datos

La información recopilada se emplea exclusivamente para:

  • Ejecutar los comandos solicitados y aplicar las acciones de moderación.
  • Recordar la configuración de cada servidor entre reinicios del bot.
  • Mantener historiales de avisos, niveles y verificaciones.
  • Detectar abusos del servicio y corregir errores.

Los datos no se venden, no se alquilan y no se usan para publicidad ni para elaborar perfiles con fines comerciales.

5. Almacenamiento y conservación

Los datos se guardan en la base de datos del bot, alojada en la infraestructura utilizada para su funcionamiento, y se conservan mientras sean necesarios:

  • La configuración y los registros del servidor se conservan mientras el bot permanezca en él.
  • Si el bot es expulsado o eliminado de un servidor, sus datos asociados se borran en un plazo máximo de 30 días.
  • Los códigos de verificación temporales caducan en minutos y se descartan automáticamente.
  • Los registros técnicos se rotan periódicamente y no se conservan de forma indefinida.

6. Seguridad

El acceso a la base de datos está restringido al responsable del bot. Las credenciales y el token del bot se guardan como variables de entorno en el servidor y nunca se incluyen en este sitio web ni en ningún código público.

Ningún sistema es completamente seguro. Si se produjera un incidente que afectara a los datos almacenados, se informará a los servidores afectados a través de los canales de soporte disponibles con la mayor brevedad posible.

7. Eliminación de datos

Puedes solicitar la consulta o la eliminación de tus datos en cualquier momento:

  • Como miembro: ejecuta /unlink para eliminar una cuenta de Roblox vinculada, o escribe a la dirección de contacto indicando tu user ID de Discord.
  • Como administrador del servidor: expulsa al bot para iniciar el borrado de los datos del servidor, o solicita la eliminación inmediata por correo indicando el ID del servidor.

Las solicitudes se atienden en un plazo razonable, normalmente inferior a 30 días. Puede pedirse una comprobación de identidad o de permisos antes de borrar datos de un servidor.

8. Servicios de terceros

Para funcionar, el bot se comunica con la API de Discord y, cuando la vinculación está activa, con la API pública de Roblox. Este sitio web carga tipografías desde Google Fonts. No se utilizan cookies de seguimiento ni herramientas de analítica publicitaria.

9. Edad mínima

El servicio está dirigido a personas que cumplen la edad mínima exigida por Discord en su territorio. No se recopilan datos de forma consciente de quienes no alcancen esa edad. Si se detecta un caso así, los datos se eliminarán al recibir el aviso.

10. Cambios en esta política

Esta política puede actualizarse cuando se añadan funciones nuevas, como el inicio de sesión con Discord o el panel de control. La fecha de la parte superior refleja siempre la última revisión. Si un cambio afecta de forma sustancial al tratamiento de los datos, se anunciará en el servidor de soporte antes de aplicarlo. Seguir usando el bot después de una actualización implica aceptar la versión vigente.
